# Maintenance notes

## Author metadata

Use `EY2234 <@Eryc123Y>` in the `authors` field of `typst.toml` for every
release. The same name is used by the author's other Typst packages
(`unofficial-monash-touying`, `unofficial-monash-report`).

Versions already on Typst Universe keep the name they were published with and
cannot be edited: `scholia:0.1.0` shows `Eric Yang <@Eryc123Y>`. The unified
name reaches Universe with the next release pull request to `typst/packages`;
no separate pull request is needed for it.
